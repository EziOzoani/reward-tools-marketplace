# Reward tools

Scoring skills for writing. Nothing to install, no key, no terminal.

## Add it to your Claude account

In Claude, open **Customize**, add this repository as a marketplace, then install **reward-tools**.
It becomes available in chat and in Cowork on the same account.

You do not need a GitHub account, an administrator, or a project folder.

## What you get

- **slop-score** — score a piece of writing for filler and long sentences, and see which part moved
  when you revise it.

## Updates

New skills and changes arrive with the next version of the plugin. You do not reinstall anything.
`releases.json` in this repository always names the current version of every skill, so you can
check what you should have.
