# Using the slop score in Cowork

For anyone who wants to improve a piece of writing. You do not need to know any code, and there is
nothing to install if a colleague has already added this to your Cowork.

## Do this

1. Open Cowork.
2. Type: **Score my writing for slop**, then paste your text and send.
3. You get back a score from 0 to 1 (higher is better) and a few named parts: plain language,
   filler words, and sentence length.
4. Improve a weak part, paste the new version, and say **score this new version**.
5. Ask **why did the score change?** It tells you which part moved.

## What good use looks like

- Read the named parts, not just the total. They tell you what to fix.
- After a change you should be able to say a sentence like "it went up because the filler words
  dropped". If you cannot, ask it to explain again.
- The score is a guide, not the goal. Stop when the weak part is better and the writing still says
  what you mean. Do not chase a perfect number.

## If something looks off

- A very short passage (under about twenty words) is too short to score and comes back as 0.0. Give
  it a fuller paragraph.
- If it shows a score without naming the parts, ask it to show the parts.
- If it says it could not produce a score, that is honest, not a fault: it will not make one up.
